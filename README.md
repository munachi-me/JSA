# JSA (JavaScript Analytics)

JSA is a toolkit for data analytics, designed to help developers load, prepare, analyze, and visualize data within a JavaScript environment.

## Repository Organization

This repository contains multiple versions of the JSA application, each representing a stage in the project's development or a specific release.

### Version Directories

- `jsa-v0.1.0`: Early-stage Node.js CLI toolkit for data inspection and KPI generation.
- `jsa-v0.2.0` - `jsa-v0.2.8`: Browser-based web applications (built with React and Vite) spanning several development phases:
    - **Phases 1–5**: Implementation of data import, transformation pipeline, analysis, visualization, insights, and dashboard builder.
    - **Phase 6**: Stabilization and end-to-end verification.

Each version directory contains its own `README.md`, `package.json`, and version-specific documentation, such as `RELEASE_NOTES.md`, `AUDIT.md`, and Phase 6 milestone documentation.
