# Phase 7 — Milestone 4 (v0.4.72)

## Conditional updates and export appearance refinements

- Update values in an existing column with ordered IF rules; conditions may reference other columns.
- Preserve unmatched cells when the fallback is blank and validate results against the target column's data type.
- Recognize common month, weekday, quarter, week, year, date/date-time, and time category labels for automatic chronological sorting in interactive HTML exports.
- Support hex color entry, recent-color reuse, and copying colors between appearance fields in Export Appearance Studio.
