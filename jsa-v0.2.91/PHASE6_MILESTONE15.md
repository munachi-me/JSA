# Phase 6 — Milestone 15 (v0.2.91)

Focus: dashboard chart fit/overflow behavior, chart sort and value controls, responsive settings, and Analysis Group by styling.

- Desktop settings use a side panel; mobile settings use a modal popup.
- Chart content fits the component dimensions by default. Expanding the chart's data-table disclosure enables scrolling so table content is not clipped.
- Dashboard chart settings support sort mode and direction; export renderers apply the configured sort.
- Show-values controls are available in chart creation and dashboard settings.
- KPI/filter cards start compact but remain resizable.
- Analysis Group by choices have accessible checkbox-card styling.
- `node_modules` is intentionally excluded from the release archive.
